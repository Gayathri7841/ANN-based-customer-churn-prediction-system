# ANN-Based Customer Churn Prediction System

A deep learning project that uses an **Artificial Neural Network (ANN)** to predict whether a customer is likely to churn based on their details.

### Tech Stack

* Python
* TensorFlow / Keras
* Scikit-learn
* Pandas
* NumPy
* Streamlit

### Features

* Customer churn prediction using ANN
* Data preprocessing and encoding
* Model training and evaluation
* Interactive Streamlit web application

### Live Demo

[Try the Streamlit App](https://ann-based-customer-churn-prediction-system-fijptwdejjpocnlrieg.streamlit.app/)

### Project Structure

* `model.h5` – Trained ANN model
* `app.py` – Streamlit application
* `.pkl` files – Saved preprocessing objects
* `requirements.txt` – Project dependencies
